# ROS 2 Hexacopter Lidar Simulation

A ROS 2 package for simulating a hexacopter drone equipped with a LiDAR sensor in Gazebo. This project serves as a 3D flight and sensor demonstration, showcasing how to enable 3D movement via velocity control and extract laser scan data from a flying hexacopter model in a simulated environment.

## 🚀 Features

* **Custom URDF:** Complete hexacopter description utilizing xacro for modularity, including 6 rotor arms.
* **Gazebo Integration:** Ready-to-use configuration for modern Gazebo with 3D velocity control plugins.
* **LiDAR Simulation:** Generates standard `sensor_msgs/LaserScan` data to demonstrate sensor integration on an aerial platform.
* **Ready to Launch:** Pre-configured launch file to bring up the environment, robot state publisher, and parameter bridges simultaneously.

## 📋 Prerequisites

Ensure you have the following installed on your system before proceeding:

* ROS 2 (Humble, Iron, or Jazzy)
* Gazebo (Ignition / Modern Gazebo)

Install the required ROS 2 dependencies:

```bash
sudo apt update
sudo apt install ros-${ROS_DISTRO}-xacro \
                 ros-${ROS_DISTRO}-ros-gz-sim \
                 ros-${ROS_DISTRO}-ros-gz-bridge \
                 ros-${ROS_DISTRO}-robot-state-publisher
```

## 🛠️ Installation & Build

1. **Navigate** to the source directory of your ROS 2 workspace:
   ```bash
   cd ~/ws_mobile/src
   ```

2. **Clone** this repository into a folder named `hexacopter_sim`:
   ```bash
   git clone https://github.com/mohit-mesh/ros2-hexacopter-sim.git hexacopter_sim
   ```

3. **Install** any remaining missing dependencies using `rosdep`:
   ```bash
   cd ~/ws_mobile
   rosdep install --from-paths src --ignore-src -r -y
   ```

4. **Build** the package:
   ```bash
   colcon build --symlink-install --packages-select hexacopter_sim
   ```

5. **Source** the newly built workspace:
   ```bash
   source install/setup.bash
   ```

## 🏃‍♂️ Usage

Launch the simulation, spawn the hexacopter, and start the ROS-Gazebo bridges using the provided launch file:

```bash
ros2 launch hexacopter_sim gazebo_model.launch.py
```

### 🎮 Teleoperation

You can manually control the hexacopter using keyboard teleoperation. First, install the `teleop_twist_keyboard` package for your distribution (e.g., Jazzy):

```bash
sudo apt install ros-jazzy-teleop-twist-keyboard
```

Once installed, open a new terminal, source your workspace, and run the teleop node:

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

Use the following keys to publish velocity commands to the drone:

* **Linear Motion (Horizontal X/Y):**
  * `i` : Move forward (+X)
  * `,` : Move backward (-X)
  * `j` : Move left (+Y)
  * `l` : Move right (-Y)
* **Altitude Control (Vertical Z):**
  * `t` : Move Up / Ascend (+Z)
  * `b` : Move Down / Descend (-Z)
* **Rotation (Yaw):**
  * `u` / `o` : Turn / Rotate counter-clockwise / clockwise
* **Stop:**
  * `k` : Immediate stop
* **Speed Adjustments:**
  * `q` / `z` : Increase / decrease max speeds by 10%

### 👁️ Visualizing LiDAR Data

Since this project focuses on LiDAR data generation in a 3D environment, visualizing the output in RViz2 is the best way to see it in action. Open a new terminal, source your workspace, and launch RViz2:

```bash
rviz2
```

* Add a **RobotModel** display to see the hexacopter.
* Add a **LaserScan** display and set the topic to `/scan` to view the simulated LiDAR points interacting with the Gazebo environment.
* Ensure your **Fixed Frame** is set correctly (e.g., `base_link`).

## 📡 Key ROS 2 Topics

Once the simulation is running, the bridge exposes these essential topics:

* `/scan` (`sensor_msgs/msg/LaserScan`): 2D laser scan data generated by the hexacopter's LiDAR.
* `/cmd_vel` (`geometry_msgs/msg/Twist`): Velocity commands for 3D flight control.
* `/tf` & `/tf_static`: Coordinate frame transforms for the hexacopter's links.
