🤖 ROS 2 Hexacopter and Lidar simulation in Gazebo

An end-to-end ROS 2 simulation package featuring a LiDAR-equipped hexacopter platform operating in Gazebo, complete with `ros_gz_bridge` topic remapping and RViz2 point cloud visualization.
